# Smart Hostel Hub

1. Project Title and Description
The Smart Hostel Hub is a responsice web application that designed for students and administrative staff at Kolej Jasmine, Universiti Technology Mara (UiTM). The portal highlighted hostel facility maintenance complaint management, occupancy tracking and operational data visualtization.

This project developed for IMS566 (Individual Project)

Live Demo (link github)

2. Feature Included
- Login page 
- Sign up page for user register
- Dashboard with an overview of Smart Hostel Operations
- Chart showing status statistics
- View of manintenance complaints tracker
- Status complaints (Eg: Urgent, Medium, Small)
- List of Blocks and Room 
- Maintenance analytics page has chart complaints by category and block resolution comparison
